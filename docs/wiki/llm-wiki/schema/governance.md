# Gobierno

- `raw/` es inmutable después de su aprobación; cambios generan una nueva versión.
- `wiki/` contiene síntesis verificable, no transcripciones.
- Cada afirmación durable se clasifica como HECHO, DECISIÓN, PREFERENCIA o PREGUNTA ABIERTA.
- Claims de código se verifican contra código/pruebas actuales.
- No persistir secretos, tokens, passwords ni PII innecesaria.
