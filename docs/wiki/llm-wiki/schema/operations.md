# Operaciones

1. INGEST: registrar la fuente aprobada, integrar páginas, enlazar y anotar `log.md`.
2. QUERY: leer `index.md`, consultar páginas relevantes y verificar contra fuentes/código.
3. LEARN: extraer solo conocimiento durable y clasificarlo antes de persistir.
4. LINT: detectar contradicciones, claims obsoletos, duplicados, huérfanas, links rotos, decisiones no aprobadas y contenido sensible.
